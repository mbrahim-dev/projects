### 🚀 Streamlit Project

This project is a web application built with **Streamlit**. It currently includes a home page and a data visualization page to explore and analyze **e-commerce data** through interactive charts.

The application is mainly developed in **Python**, with **HTML, CSS, JavaScript and JSON** for custom components and interactive features.

**Want to explore the app ?** Click here to discover my [**Streamlit App**](https://projects-data.streamlit.app/)

---

### 📁 Project Structure

The project is organized into two main folders:

- **`dataset/`** – Contains the data used by the application.
- **`dev/`** – Contains the Python code, application pages and custom interface components.

---

### 📊 Dataset

The `dataset/` folder contains the **fictional e-commerce dataset** used by the application for data analysis and visualization.

- **`sales_performance.csv`** – Contains e-commerce sales data used for analysis and visualization.

---

### 💻 Application Development

The `dev/` folder contains the source code and resources used to build the application.

- **`code.py`** – main application file.
- **`shared.py`** – shared functions and components used across pages.
- **`page_home.py`** – home page.
- **`page_overview.py`** – dataset overview and data dictionary.
- **`page_time_analysis.py`** – analysis of sales trends over time.
- **`page_product_analysis.py`** – analysis of product and category performance.
- **`page_geographical_analysis.py`** – geographical analysis of sales performance.

---

### 🎨 Custom Assets

The `assets/` folder contains additional resources used to customize the interface and enhance interactivity.

- **`css/style.css`** – custom styling.
- **`html/components.html`** – custom HTML components.
- **`js/geo_tooltip.js`** – javaScript for geographical map tooltips and interactions.

---

### 📦 Requirements

The **`dev/requirements.txt`** file lists the Python packages required by the application.
